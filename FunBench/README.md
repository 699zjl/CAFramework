[MICCAI2025] [FunBench: Benchmarking Fundus Reading Skills of MLLMs](https://www.arxiv.org/abs/2503.00901)

FunBench is a novel visual question answering (VQA) benchmark designed to comprehensively evaluate MLLMs' fundus reading skills.

Code and description are available at [https://github.com/ruc-aimc-lab/FunBench](https://github.com/ruc-aimc-lab/FunBench)
